# Send 和 Sync：能不能跨线程

Send 表示值可以安全地转移到另一个线程。Sync 表示共享引用可以安全地在线程间传递，也就是 `&T: Send`。

| 类型 | 常见限制 |
|---|---|
| `Rc<T>` | 不是 Send，也不是 Sync |
| `RefCell<T>` | 不是 Sync；当 T 是 Send 时可以是 Send |
| `Arc<T>` | 需要 T 满足对应的 Send、Sync 条件 |
| `Mutex<T>` | 在 T 满足必要条件时，提供跨线程同步访问 |

这些是标记 trait，大多数结构体会根据字段自动得到结果。普通代码通常只需要正确组合现有类型。

不要为了通过编译就手写 `unsafe impl Send/Sync`。这样是在向编译器承诺你已经证明跨线程访问安全，需要检查所有相关操作和不变量。
