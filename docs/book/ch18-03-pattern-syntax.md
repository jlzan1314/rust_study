# 常用模式写法

先从最常见的几种开始：

| 模式 | 含义 |
|---|---|
| `1` | 匹配具体值 |
| `1 | 2` | 匹配任一情况 |
| `1..=5` | 匹配包含两端的范围 |
| `(x, y)` | 拆开元组 |
| `Point { x, y }` | 拆开结构体 |
| `Some(value)` | 拆开枚举成员 |
| `_` | 忽略一个值，不绑定 |
| `..` | 忽略其余部分 |
| `name @ pattern` | 检查模式，同时保留被匹配的值 |

```rust
let value = Some(4);
let label = match value {
    Some(number @ 1..=5) if number % 2 == 0 => "小偶数",
    Some(_) => "其他数字",
    None => "没有数字",
};
assert_eq!(label, "小偶数");
```

`if` 后面的条件叫匹配守卫，适合表达模式本身不好表达的限制。有守卫的分支不一定覆盖所有值，仍需兜底。

模式里直接写名字会绑定新变量，不是自动比较外部同名变量。需要与外部变量比较时用守卫。

`_name` 仍然会绑定值，可能取得所有权；`_` 才是真正忽略。按值解构非 Copy 字段可能移动它；只读时可以匹配引用，或在需要的位置使用 ref。

元组或切片里通常只能有一个 `..`，否则编译器无法判断中间各部分该怎么分配。
