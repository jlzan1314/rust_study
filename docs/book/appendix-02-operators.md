# 常见运算符和符号

同一个符号在不同位置可能有不同意思，结合上下文看。

| 写法 | 常见含义 |
|---|---|
| `+ - * / %` | 算术运算；`*value` 也表示解引用 |
| `== != < <= > >=` | 比较 |
| `&& || !` | 逻辑与、或、非；前两者短路求值 |
| `& | ^ << >>` | 按位运算；`&value` 也表示借用 |
| `= += -= *=` | 赋值或复合赋值 |
| `&T`、`&mut T` | 引用类型 |
| `*const T`、`*mut T` | 裸指针类型 |
| `::` | 路径分隔 |
| `.` | 访问字段或方法 |
| `..`、`..=` | 不含右端或包含右端的区间；`..` 也可忽略其余字段 |
| `?` | 遇到错误或 None 时提前返回 |
| `->` | 函数返回类型 |
| `=>` | match 分支或宏规则的右侧 |
| `'a` | 生命周期名；循环标签也使用单引号 |
| `|x| ...` | 闭包；模式中的 `|` 表示任一情况 |
| `_` | 忽略值，或让编译器推断类型 |
| `@` | 绑定名称并检查子模式 |
| `!` | 宏调用标记、逻辑非，或 never 类型 |
| `#[...]`、`#![...]` | 项属性、当前项或 crate 的内部属性 |
| `<T>`、`::<T>` | 泛型参数；后者常用于表达式里指定类型 |

数组写 `[T; N]`，切片写 `[T]`，元组写 `(A, B)`，单元类型写 `()`。有疑问时加括号表达运算顺序，不要靠读者背优先级。
