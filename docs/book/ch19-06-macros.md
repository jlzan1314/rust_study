# 宏：在编译时生成代码

函数接收值并在运行时执行；宏接收代码形式的输入，在编译阶段展开。vec! 能接受多个元素，就是常见宏。

```rust
macro_rules! pair {
    ($left:expr, $right:expr) => {
        ($left, $right)
    };
}
assert_eq!(pair!(1 + 2, 4), (3, 4));
```

`$left:expr` 匹配一个表达式，展开时用捕获到的代码替换。重复模式可以匹配多个参数，但复杂宏的报错和维护成本也会上升。

过程宏接收并返回 TokenStream，常见三类：

- derive 宏：自动生成 trait 实现，例如 `#[derive(Debug)]`。
- 属性宏：通过属性处理或生成项。
- 函数式过程宏：使用 `name!(...)` 形式调用。

自定义过程宏通常放在独立、标记为 `proc-macro = true` 的库 crate，解析和生成语法常用 syn、quote。derive 名称通常只是入口，真正输出的是生成的实现代码。

能用函数或泛型清楚表达时，优先用它们。需要处理不同代码结构或消除重复声明时，再考虑宏。
