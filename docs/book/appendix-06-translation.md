# 译本和来源

本地内容依据 Rust 中文翻译项目的《Rust 程序设计语言》改写，原作者和译者信息、源码版本及许可证见 [README](README.md)。

需要对照完整表述时，查看 [原中文站点](https://rustwiki.org/zh-CN/book/)；需要确认当前稳定版行为时，查看 [官方英文书](https://doc.rust-lang.org/book/) 和标准库文档。

术语在这里尽量固定：ownership 译作所有权，borrow 译作借用，trait 保留英文，crate 指编译单元，Package 指 Cargo 管理的项目。首次遇到时先理解用途，再记名称。
