# 先分清数据类型

Rust 在编译时必须知道每个值的类型。大多数时候能自动推断，推不出时你需要标注。

| 类型 | 保存什么 | 例子 |
|---|---|---|
| `i32`、`i64` | 有正负的整数 | `-3` |
| `u32`、`u64` | 非负整数 | `3` |
| `usize` | 与平台地址宽度一致的无符号整数，常用于索引 | `values.len()` |
| `f32`、`f64` | 浮点数，存在精度误差 | `3.5` |
| `bool` | 真或假 | `true` |
| `char` | 一个 Unicode 标量值 | `'你'` |
| 元组 | 固定数量、可以不同类型的值 | `(1, true)` |
| 数组 | 固定长度、同一种类型的值 | `[1, 2, 3]` |

未受约束的整数字面量通常默认为 i32，浮点数字面量通常默认为 f64。不同数字类型一般不能直接相加，应明确转换，并检查是否会截断或溢出。

```rust
let point: (i32, i32) = (3, 4);
let (x, y) = point;
let values: [i32; 3] = [10, 20, 30];
assert_eq!(x + y, 7);
assert_eq!(values[1], 20); // 索引从 0 开始。
assert_eq!(values.get(9), None); // 安全处理越界。
```

整数除法会舍去小数部分：`5 / 2` 是 2。数组直接索引越界会 panic，长度可变的序列使用 Vec。

整数溢出不能依赖“自动绕回”：开启溢出检查时会 panic。需要明确行为时，使用 `checked_add`（返回 Option）、`wrapping_add`（绕回）、`saturating_add`（停在边界）等方法。
