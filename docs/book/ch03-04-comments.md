# 注释写“为什么”

普通注释用 `//`，块注释用 `/* ... */`。注释应解释原因、限制或容易误解的地方，避免逐句翻译代码。

```rust
// 用字节数计费，因此这里不用 chars().count()。
let billable_bytes = "你好".len();
assert_eq!(billable_bytes, 6);
```

文档注释有两种常见形式：`///` 说明后面的函数、类型等；`//!` 说明当前模块或 crate。它们会进入 `cargo doc` 生成的文档。

```rust
/// 返回两个整数的和。
fn add(a: i32, b: i32) -> i32 {
    a + b
}
assert_eq!(add(1, 2), 3);
```

公开接口的文档适合说明参数含义、返回值、失败条件，再给一个最小例子。
